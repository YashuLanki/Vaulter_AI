HOW TO START - VAULTER AI
=========================


1.  UNZIP THIS FIRST.
    Right-click the "Vaulter AI" zip, choose "Extract All...",
    Select the folder you prefer and then click Extract.


2.  Open the "quick_start" folder again and double-click
    "Setup Vaulter AI".


3.  Wait.  A black window shows what it is doing.
    Takes about 5 minutes.  Leave it open.

      - If it offers to install Python, say yes.
      - If it then asks you to double-click Setup again, do that.


4.  Fully quit Claude Desktop, then open it again.
    Done.  Try asking it:  "What do we know about <a property>?"



IF WINDOWS WARNS YOU
--------------------

  "Unknown Publisher"           ->  click Run
  "Windows protected your PC"   ->  click More info, then Run anyway

  Both are normal for a downloaded file.


GOOD TO KNOW
------------

  Keep the folder where Setup puts it.  Moving or renaming it later
  disconnects Vaulter AI - if that happens, run Setup again from the
  new location.

  Setup is safe to run as many times as you like.

  Stuck?  Send a photo of the window to Yashu.
